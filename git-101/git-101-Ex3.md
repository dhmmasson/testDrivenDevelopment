# Exercice 3

## Description

As in the Ex 2, every members will edit the same file. But this time, you will create `branches` to minimize conflict and facilitate merging.

# All Members

You have decided to update the team members information. You will modify the README and add some information about yourself.

1. Make sure that your local copy is up to date, if not pull any modification from the remote repository.
2. Create a new local branch (call it `your_name_ex3`)  
![alt text](branch.png "Create new branch")

> _Fig. 1 That's here_

1. Click on "Bring my changes to 'branch_name'" and validate 'switch branch'
2. Publish your branch on the remote directory  
![alt text](publish.png "Publish new branch")

> _Fig. 2 That's here_

1. Modify the README file, add some elements about yourself in the team member section.
2. Commit your modification (Make sure you are on the new branch you just created!)
3. If you are not first in the list move yourself up.
4. Commit your modification
5. WAIT for the other to have committed their change locally
6. push your commit(s) to the remote
7. WAIT
