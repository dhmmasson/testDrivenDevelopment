# manifest.json

## Examples

your first manifest could be:

```json
{
  "version" : "1.1.0",
  "features" : [
	  "version",
	  "help",
	  "version",
	  "filenames",
	  "parameters",
	  "debug",
  ]
}
```

Your second manifest after implementing the features ```avgAlt``` and ```maxAlt```

```json
{
  "version" : "1.2.0",
  "features" : [
	  "version",
	  "help",
	  "version",
	  "filenames",
	  "parameters",
	  "debug",
	  "avgAlt",
	  "maxAlt"
  ]
}
```
